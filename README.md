# Ethical Lab KE - Staff Portal

A fake company staff portal built for **cybersecurity training only**.
All data is fake. Do NOT use on a real company.

Live Demo: https://ethicallab.netlify.app

---

## What Is This?

This is a lab site to teach classmates how hackers break into weak logins.

It looks like a real company portal, but everything is intentionally vulnerable.

## Features

- Staff Login Portal
- Admin Vault - Hidden
- Employee Database - Fake
- Company Secrets Vault - Fake
- SQL Injection Simulation
- Weak Credentials Lab
- Register / Login UI
